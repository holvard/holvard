# Holvard format specification

This directory will hold the Holvard format spec:

- the card format (QR code, 33 SLIP-39 words, format version, vault fingerprint)
- the vault file format (an age file and its metadata)
- step-by-step recovery that works without Holvard software

Version 1 is frozen once published; later versions only add.
