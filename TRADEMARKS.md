# Holvard trademark policy

The code is open source; the name "Holvard" identifies the official project and
the hosted service.

- **Fine without asking:** running a self-hosted Holvard instance, saying it is
  "powered by Holvard", and writing about or linking to the project.
- **Fine for forks and other implementations:** describing them as
  "compatible with Holvard".
- **Not allowed:** calling a fork, another implementation or a hosted service
  "Holvard", or using the name or logo in a way that suggests it is run or
  endorsed by the Holvard project.

Questions: open an issue on <https://github.com/holvard/holvard>.
