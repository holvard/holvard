# Security policy

Holvard is in early development and not yet fit to protect real data.

Please report vulnerabilities privately through
[GitHub security advisories](https://github.com/holvard/holvard/security/advisories/new),
not as public issues. We aim to acknowledge reports within 7 days.

In scope: `holvard-core`, the `holvard` CLI, the format spec, the recovery page
and the release process (signing and reproducible builds).
